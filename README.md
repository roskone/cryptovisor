# Криптовизор

Интерактивный пошаговый визуализатор шифров для лекций: шифр Цезаря, XOR, столбцовая перестановка.

## Запуск

```bash
.venv/bin/python main.py
```

Зависимости: `pip install -r requirements.txt` (PySide6).

## Темы оформления

Две темы, переключаются клавишей `T` или кнопкой `◐` справа в панели вкладок:

- **glass** (по умолчанию) — стеклянная панель на размытом фоне, Unbounded везде.
- **editor** — плоский редактор кода: тёмно-графитовый фон, моноширинный
  шрифт внутри сцены, точки-статусы в панели, журнал шагов внизу. Запуск сразу в ней:
  `python main.py --editor`.

## Тесты

```bash
.venv/bin/python -m unittest discover -s tests
```

## Структура

- `app/core/` — логика шифров без Qt; каждый алгоритм возвращает список шагов (`Step`)
- `app/ui/scenes/` — сцены визуализации (по одной на алгоритм), рисуют текущий шаг
- `app/ui/sidebar.py` — панель ввода, `app/ui/transport.py` — управление воспроизведением
- `app/ui/main_window.py` — связывает всё вместе, горячие клавиши

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел / → | шаг вперёд |
| ← | шаг назад |
| Home / End | в начало / в конец |
| Enter | авто-воспроизведение |
| + / − | быстрее / медленнее |
| 1 · 2 · 3 | выбор алгоритма |
| E / D | шифровать / дешифровать |
| M | крупные шаги (по символу / столбцу) |
| F | полный экран |
| T | сменить тему |
| Esc | выйти из поля ввода / из полного экрана |
